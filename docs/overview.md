# Overview of this project

The intension of the program is to have a small backend for a web application with some Rest endpoints interacting with Postgres. The goal is to show a typical Java / Spring Boot programmer how Rust works and enable him to compare the two technologies. Which crate to use for interacting with Postgres is not decided yet.

Another goal is to demonstrate the quality of Postgres. This is regard of usability but also performance and throughput.
